# Challenge 10: Color Contrast

**Difficulty:** Intermediate  
**Skill focus:** Accessibility, CSS color choices

## The problem

Open `index.html`. The body text is hard to read because the color contrast against the background is too low.

## Your task

1. Identify the low-contrast text color in the CSS.
2. Update it so the text is clearly readable on the background (aim for strong contrast, not a tiny tweak).
3. Keep the Integify purple brand feel for headings/accents if you can.
4. Commit and open a PR explaining what you changed and why contrast matters.
