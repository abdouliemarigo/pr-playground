# Challenge 08: Missing Alt Text

**Difficulty:** Beginner  
**Skill focus:** Accessibility (a11y), HTML attributes

## The problem

Open `index.html`. The logo image loads, but it has no meaningful alternative text for screen readers (and for when the image fails to load).

## Your task

1. Find the image in `index.html`.
2. Set a clear, useful `alt` attribute that describes the image (for example, the company name).
3. Do not change the image file or layout.
4. Commit and open a PR explaining why alt text matters and what you chose.
