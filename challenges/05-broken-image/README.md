# Challenge 05: Broken Image

**Difficulty:** Beginner  
**Skill focus:** HTML, file paths, verifying in the browser

## The problem

Open `index.html` in a browser. The Integify logo should appear under the heading, but the image is broken.

## Your task

1. Find why the image does not load.
2. Fix the path in `index.html` so the logo displays.
3. Open the page in a browser to confirm it works.
4. Commit and open a PR explaining what was wrong and how you verified the fix.
