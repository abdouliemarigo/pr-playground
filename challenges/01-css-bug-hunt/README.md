# Challenge 01: CSS Bug Hunt

**Difficulty:** Beginner
**Skill focus:** CSS, attention to detail

## The problem

Open `index.html` in a browser. The cards under "Web Development / Mobile Apps / AI Integration" should have a subtle drop shadow, but they don't.

## Your task

1. Find the bug in `css/style.css`.
2. Fix it so the shadow appears.
3. Open the page in a browser to confirm the fix works.
4. Commit and open a PR explaining what was wrong and how you found it.
