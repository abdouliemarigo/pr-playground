# Challenge 11: Update the Docs

**Difficulty:** Beginner  
**Skill focus:** Documentation PRs, following instructions carefully

## The problem

The site lists **three** services, but `SERVICES.md` is out of date — it only documents two of them, and one description is wrong.

## Your task

1. Open `index.html` and read the three services shown on the page.
2. Update `SERVICES.md` so it matches the page:
   - Include all three services
   - Fix any incorrect descriptions
   - Keep the same markdown structure (heading + bullet list)
3. Do not change `index.html`.
4. Commit and open a PR summarizing what was outdated and what you corrected.
