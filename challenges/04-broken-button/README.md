# Challenge 04: Broken Button

**Difficulty:** Beginner+
**Skill focus:** Basic JavaScript, using browser dev tools to debug

## The problem

Click the button. Nothing happens, it should count clicks and show a message.

## Your task

1. Open the browser console (right-click → Inspect → Console) and find the error.
2. Fix the bug in `js/app.js`.
3. Confirm the button now counts clicks correctly.
4. Commit and open a PR explaining the bug and how you diagnosed it (mention the console error).
