# Challenge 03: Missing Footer

**Difficulty:** Beginner
**Skill focus:** HTML/CSS, building something from scratch (not just fixing)

## The problem

This page has no footer at all.

## Your task

1. Add a `<footer>` at the bottom of `index.html`.
2. Include: your name, the current year, and a short line like "Built for Integify PR Playground".
3. Style it so it looks intentional, not just plain text (background color, padding, centered text, etc. — your choice).
4. Commit and open a PR with a screenshot or description of your footer design.
