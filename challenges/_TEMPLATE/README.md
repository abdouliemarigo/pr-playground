# Challenge NN: Title

**Difficulty:** Beginner
**Skill focus:** e.g. CSS, attention to detail

## The problem

Describe what the candidate *observes*, not what's wrong under the hood. Point them
at the file to open and the symptom to look for.

Example: "Open `index.html` in a browser. The cards should have a subtle drop
shadow, but they don't."

## Your task

1. Find the bug in `path/to/file`.
2. Fix it.
3. Open the page in a browser to confirm the fix works.
4. Commit and open a PR explaining what was wrong and how you found it.
