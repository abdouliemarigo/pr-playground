# Challenge 06: Responsive Cards

**Difficulty:** Beginner+  
**Skill focus:** CSS layout, checking at small screen widths

## The problem

Open `index.html` and resize the browser to a phone-sized width (around 375px). The three service cards should stack vertically, but they overflow horizontally instead.

## Your task

1. Find the CSS issue in `css/style.css` that breaks the mobile layout.
2. Fix it so the cards wrap/stack cleanly on small screens.
3. Check at both desktop and mobile widths.
4. Commit and open a PR explaining the bug and how you verified the fix (mention the viewport width you tested).
