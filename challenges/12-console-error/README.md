# Challenge 12: Console Error

**Difficulty:** Beginner+  
**Skill focus:** JavaScript debugging, browser console

## The problem

Open `index.html`. The page title in the hero should say **Welcome to Integify**, but it stays blank. The browser console shows an error.

## Your task

1. Open the browser console and read the error.
2. Fix the bug in `js/app.js`.
3. Confirm the welcome message appears and the console is clean.
4. Commit and open a PR explaining the error message and your fix.
