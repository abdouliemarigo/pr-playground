# Challenge 09: Broken Link

**Difficulty:** Beginner  
**Skill focus:** HTML links, verifying navigation

## The problem

Open `index.html` and click **Contact**. It should jump to the Contact section at the bottom of the page, but nothing happens (or you land in the wrong place).

## Your task

1. Find the broken link in the navigation.
2. Fix it so **Contact** scrolls to the Contact section.
3. Confirm by clicking the link in the browser.
4. Commit and open a PR explaining what was wrong with the `href`.
